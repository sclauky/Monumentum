# Frontend

Pour lancer tout le projet en une seule commande sous Windows, suis les
instructions du [README racine](../../README.md). Si tu préfères démarrer le
frontend séparément, suis les étapes ci-dessous.

## Développement

Depuis ce dossier (web), installe les dépendances et lance le serveur :

```bash
npm ci
npm run dev
```

Clique ensuite sur le lien dans le terminal, ou directement ici: http://localhost:5173/

Pour créer la
version de production, utilise :

```bash
npm run build
```
